# Code of conduct

Doorcheck follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and assume good faith, criticize code rather than people, and
remember that the projects Doorcheck scans are someone's unpaid work.

To report behavior that breaks it, use GitHub's private vulnerability reporting
on this repository and say it's a conduct report. Reports are read only by the
maintainer and kept confidential.
